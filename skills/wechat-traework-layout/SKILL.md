# 公众号文章排版（TraeWork 技能蒸馏版）

来源：TraeWork 分享「排版公众号文章」工作流
（https://share.traecontent.cn/share/S8F7P6EMRLJ48I）

## 用途

把 Markdown / 文本 / 采集到的新闻内容，排成可直接粘贴进微信公众号后台编辑器的 HTML 公众号文章。
工作台“内容制作 → 图文制作”默认使用本技能。

## 核心原则

1. 正文与事实一字不改；只加导语、小标题与留白。
2. 所有样式写成内联 style，粘贴到公众号编辑器不掉格式。
3. 先读内容判断品类，再选视觉风格：
   - 文化 / 情感：暖茶色、居中诗体、宽松行距、克制导语；
   - 财经 / 数据：结论前置、数据加粗、卡片/表格、数字图表；
   - 时政 / 资讯：灰底事实卡、时间戳骨架、短段高频加粗；
   - 娱乐 / 八卦 / 搞笑：轻松配色、短句分段、语气词少用、留钩子。
4. 图片策略：
   - 原文有图 → 引用原图（时政/国内无图不硬配）；
   - 娱乐/八卦/搞笑/游戏无图 → 生成手绘漫画风格插画；
   - 财经可生成数据图表（柱状/折线/双轴）。
5. 结尾给来源、免责声明（金融内容必带“不构成投资建议”）。

## 输出结构

```html
<section style="max-width:680px;...">
  标题（大标题）
  导语（一句克制引入）
  正文（保留原文，短段/引用块/加粗关键句）
  收尾（留白 + 来源声明）
</section>
```

## 发布路径

- 默认：复制 HTML → 粘贴到 mp.weixin.qq.com 图文编辑器；
- 备选：导出 Word 导入后台；
- 直发：需要认证服务号 AppID/AppSecret + 出口 IP 白名单。
