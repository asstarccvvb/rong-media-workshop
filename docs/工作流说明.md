# 新媒体运营工作流说明

## 来源

- 基础参考：[工作流程 - TraeWork](https://share.traecontent.cn/share/HP87TC-YLUHHN7?enter_from=pc)（金融新闻视频号自动化工作流：多维度搜索 → 爆点判断 → 总结分析 → 通讯稿文案 → 保存文件 → 本地实时看板）
- 方法论参考：TraeWork 官方《用 TRAE Work，1 个人也能轻松做好自媒体》六环节流水线（情报输入 → 选题决策 → 内容生产 → 多平台适配 → 物料封装 → 数据复盘）

## 六段式设计（本工作台实现）

| 阶段 | 输入 | 处理 | 输出 |
|---|---|---|---|
| ① 搜集信息 | 行业/赛道、信息源、手动素材 | 多源抓取、去重 | 原始信息库（含来源与时间） |
| ② 整合信息 | 原始信息库 | 按时间/重要度合并 | 热点简报 |
| ③ 信息分类 | 热点简报 | 关键词分类 + 传播性评级 | 分类清单 |
| ④ 信息处理 | 分类清单 | 提炼关键数据、写文案/口播稿 | 成稿文案 |
| ⑤ 制作海报和视频 | 成稿文案 | 海报 SVG + 分镜脚本 | 可发布物料 |
| ⑥ 分发 | 物料 | 多平台改写 + 发布清单 | 发布包 |

## 与 TraeWork 参考的对应关系

- TraeWork 的「多维度搜索」→ 本工作台 ① 搜集信息
- TraeWork 的「判断是否有爆点」→ 本工作台 ③ 信息分类（传播性评级）
- TraeWork 的「总结与分析、撰写视频号文案」→ 本工作台 ④ 信息处理
- TraeWork 的「保存文件 + 本地看板」→ 本工作台 ⑤ 制作海报和视频、⑥ 分发

## 扩展建议

- 接入真实平台 API（如视频号助手、抖音开放平台）后，⑥ 分发可升级为自动发布
- 接入 Remotion / 剪映草稿，⑤ 可输出可直接剪辑的视频工程
- 把 ① 设成 Codex 定时任务，每天自动收集热点简报
